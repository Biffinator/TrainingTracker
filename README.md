# Hybrid Training Tracker V3.11.0

Run/bike quality work now alternates by week instead of always landing on running. Week 1 (Base) and week 3 (VO2max) keep running as the primary endurance day, with the Norwegian 4x4 intervals staying on the run. Week 2 (Tempo) and week 4 (Deload) shift the Tuesday quality/easy session and Thursday steady session to biking, with a tempo effort on the bike instead of intervals. The Saturday long day already alternated between run and bike and is unchanged.
