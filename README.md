# Hybrid Training Tracker V3.15.1

Fixes a caching bug that could break the app entirely, including cloud sign-in. Only app.js, plunge-ui.js, and style.css ever carried cache-busting version numbers - every other internal file (core.js, cloud.js, cloud-api.js, program.js, training.js, wellness.js, wellness-ui.js, suggestions.js, suggestions-ui.js, idle-sync.js, session.js, deletion.js, plunge.js) was referenced by a bare filename that never changed. When core.js recently gained new exports that app.js depends on, a stale cached copy of core.js served alongside a fresh app.js caused the whole app.js module to fail to load - silently disabling every feature on the page, sign-in included, since no code ran at all. Every internal import now carries a matching version query string, and the service worker's precache list was rebuilt to cover every module (it was previously missing training.js, wellness.js, wellness-ui.js, suggestions.js, and suggestions-ui.js entirely).
