# Hybrid Training Tracker V3.12.0

Treadmill entries now state they follow the cold plunge, and target 13-15% incline on lift days (Mon/Wed); Tuesdays in weeks 2-3 (the hard cardio days) drop to a short easy walk instead of a full incline session. The live plunge timer now has an adjustable 1-5 second countdown before it starts, an audible tone when the countdown ends and again when the goal time is reached, and the saved "time of day" now reflects the true start of the timer (after the countdown) rather than the moment you tapped Start. Also fixed two latent bugs: the weekly workload calculation and the calendar icon classifier were both matching "cold plunge" anywhere in a task's name instead of only at the start, which the new treadmill wording exposed.
